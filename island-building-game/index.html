Tiny Block

Island Building Game

A 2D One Block Skyblock survival crafting game where every material can become a new discovery.

Starting world

Tiny Block starts on one mineable block in a purpose-built 2D mode included with the game.

Progression

The world grows through mining, material reactions, crafting, plants, and creatures unique to Tiny Block.

Fresh content

Tiny Block generates a new structure daily and a new biome weekly, based on your discoveries.

Every world is different

Biomes form new landscapes

These are the core environments, not fixed maps. Each seed rearranges terrain, caves, water, structures, plants, and creatures into a different world.
