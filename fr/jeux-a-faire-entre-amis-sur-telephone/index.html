Jeux à faire entre amis sur téléphone

Tiny Block transforme deux téléphones en un même monde de survie et de construction qui continue d’évoluer avec vos découvertes.

Tiny Block

Construisez un monde ensemble

Téléchargez Tiny Block gratuitement sur iOS ou Android. Rejoignez un monde public ou partagez un code d’invitation, puis minez, fabriquez, explorez et parlez grâce au chat vocal de proximité.

Gratuit sur mobile

Les deux joueurs peuvent commencer gratuitement sur iPhone, iPad ou Android.

Public ou sur invitation

Trouvez un monde ouvert ou gardez la session entre amis avec un code.

Voix de proximité

Le bouton micro active ou coupe la voix, qui devient plus faible lorsque les joueurs s’éloignent.

Quel jeu gratuit faire entre amis sur téléphone ?

Tiny Block est un jeu de survie-construction gratuit avec des mondes multijoueurs partagés.

Peut-on créer un monde privé ?

Oui. Créez un monde avec code d’invitation et partagez-le avec vos amis.

Le chat vocal est-il intégré ?

Oui. Tiny Block inclut un chat vocal de proximité dans ses mondes multijoueurs.
