Minecraft × Tiny Block

Was ist ähnlich – und was ist anders?

One Block ist in Minecraft meist eine Community-Karte oder Server-Herausforderung. In Tiny Block ist One Block ein integrierter Spielmodus mit eigener Entdeckungsschleife.

Minecraft One BlockTiny Block
StartweltEine Community-Marketplace-Welt startet in 3D Minecraft auf einem regenerierenden Block.Tiny Block startet auf einem abbaubaren Block in einem integrierten 2D-Modus.
FortschrittDer zentrale Block liefert vom Kartenautor festgelegte Ressourcen; danach gelten Minecraft-Handwerk und -Bauen.Die Welt wächst durch Abbau, Materialreaktionen, Handwerk, Pflanzen und eigene Kreaturen.
Neue InhalteWeitere Inseln, Phasen, Bosse und Updates hängen von der jeweiligen Marketplace-Karte oder dem Server ab.Tiny Block erzeugt täglich eine neue Struktur und wöchentlich ein neues Biom – basierend auf deinen Entdeckungen.
